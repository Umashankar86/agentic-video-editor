# Music library

Place royalty-free `.mp3`, `.wav`, `.m4a`, or `.ogg` tracks here. Descriptive names help the music agent choose well, for example:

- `upbeat-corporate-120bpm.mp3`
- `calm-cinematic-ambient.wav`
- `dark-tension-electronic.mp3`

If the prompt names an uploaded track, the agent can instead use that file from `uploads/`. Music selection never downloads copyrighted audio automatically.
